# ball-app

The built screens of the Oatlands School Ball app, served by GitHub Pages.

Nothing here is edited by hand. The source lives in the private repository
`oatlandsball/oatlands-ball` (folder `app/`) and is published with `tools/publish-app.sh`.
No data and no keys live here: everything the app shows comes from the ball's API.

- `/test/` is the test copy (not indexed, reads the test sheet).
- `/` is the live app (once published).
